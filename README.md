# Running Coach – Mezza maratona 20/12/2026

Questa cartella raccoglie il contesto, le decisioni e il piano di allenamento concordati in conversazione con Claude Code, così da poterli usare come base per creare agenti "coach" che commentano le attività e tengono traccia di progressi e cambi di allenamento.

## Contenuto

| File | Descrizione |
|---|---|
| `athlete-profile.md` | Profilo dell'atleta: soglie, zone di ritmo, obiettivi, vincoli |
| `training-plan.md` | Piano completo settimana per settimana (12 settimane, 29/9 – 20/12/2026) |
| `decisions-log.md` | Storico cronologico delle discussioni, modifiche al piano e motivazioni |
| `intervals-integration.md` | Come il piano è stato caricato su Intervals.icu, problemi incontrati e regole tecniche |
| `agents-brief.md` | Bozza dei requisiti per gli agenti coach (ruoli, input, output, regole) |
| `progress-log.md` | Registro vuoto da aggiornare con test, gare e cambi di piano |
| `plan-events.json` | Elenco degli eventi creati su Intervals.icu (ID, data, nome), utile per aggiornarli |

## Obiettivo in breve

- Gara obiettivo: mezza maratona domenica 20/12/2026, in 1:35 (4:30/km).
- Gara intermedia: 10 km domenica 29/11 (test) e mezza tranquilla domenica 13/12.
- Struttura: corsa martedì, venerdì e domenica; bici sui rulli (Zwift) giovedì; forza + pliometria lunedì.

Ultimo aggiornamento: 29/09/2026 (data della conversazione).
